## Selected Impact

> **SGRA** &nbsp;·&nbsp; Oracle APEX, PL/SQL, PowerShell, Docker, GitLab CI/CD
> Every SharePoint governance change meant raising an admin ticket. I architected the self-service replacement from scratch. **250 site owners now make these changes themselves, and a 2 to 5 day wait became 2 to 3 hours.**

> **MyOracle Home** &nbsp;·&nbsp; React, SPFx, TypeScript, Fluent UI, MS Graph
> Oracle's legacy intranet was being decommissioned. I delivered the web part layer, 10+ metadata-driven React/SPFx components, so content authors compose pages without a developer shipping code. **Recognised with Oracle's Summit Award, FY26 Q2.**

> **AI Agent Governance** &nbsp;·&nbsp; PL/SQL, SCIM, identity automation
> Designed the platform that takes internal AI agents from request through review to release, **200+ agents through it so far**, and automated the identity provisioning underneath. **Account onboarding went from 1 to 2 weeks down to 2 days.**

> **CDLP** &nbsp;·&nbsp; Office 365 Management Activity API, Purview
> Built the DLP analytics backend that gave compliance teams **their first centralised view of SharePoint data-loss incidents.**

> **SLD** &nbsp;·&nbsp; K2 SmartForms, C#, Swagger, ADFS/SSO
> Subcontractors were processing lot dispositions over email. I built the approval workflow that replaced it. **It became the standard tool and is still in production five years later.**
